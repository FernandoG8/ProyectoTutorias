================================================================================
  SISTEMA DE GESTIÓN DE TUTORÍAS - DOCKER QUICK START
================================================================================

✅ PASO 1: INSTALAR DOCKER
  - Descargar: https://www.docker.com/products/docker-desktop
  - Instalar y abrir Docker Desktop
  - Verificar: docker --version

✅ PASO 2: NAVEGAR AL DIRECTORIO
  cd backend/

✅ PASO 3: INICIAR SERVICIOS
  docker-compose up -d

  Esto inicia:
  - MySQL 8.0 (puerto 3306)
  - Spring Boot Backend (puerto 8080)

✅ PASO 4: VERIFICAR SERVICIOS
  docker-compose ps

  Deberías ver:
  - gestion-tutorias-mysql    Up (healthy)
  - gestion-tutorias-backend  Up (healthy)

✅ PASO 5: ACCEDER A LA APLICACIÓN

  API Base:        http://localhost:8080
  Swagger UI:      http://localhost:8080/swagger-ui.html
  API Docs:        http://localhost:8080/api-docs
  Health Check:    http://localhost:8080/api/dashboard/health

================================================================================
  COMANDOS COMUNES
================================================================================

Ver logs:
  docker-compose logs -f backend

Detener servicios:
  docker-compose stop

Reiniciar servicios:
  docker-compose restart

Acceder a MySQL:
  docker-compose exec mysql mysql -u tutorias_user -p gestion_tutorias
  (contraseña: tutorias_password)

Reconstruir e iniciar:
  docker-compose up -d --build

Limpiar todo (incluyendo datos):
  docker-compose down -v

================================================================================
  EJEMPLOS DE API
================================================================================

1. Health Check:
   curl http://localhost:8080/api/dashboard/health

2. Crear Semestre:
   curl -X POST http://localhost:8080/api/semestres \
     -H "Content-Type: application/json" \
     -d '{
       "codigo": "2025-2026-F1",
       "nombre": "Semestre Agosto 2025",
       "fechaInicio": "2025-08-01",
       "fechaFin": "2026-01-31"
     }'

3. Listar Semestres:
   curl http://localhost:8080/api/semestres

4. Dashboard Estadísticas:
   curl http://localhost:8080/api/dashboard/estadisticas

================================================================================
  TROUBLESHOOTING
================================================================================

Problema: MySQL no se conecta
  Solución:
    docker-compose restart mysql
    docker-compose logs mysql

Problema: Puerto ya en uso
  Solución:
    lsof -i :8080
    (editar docker-compose.yml y cambiar puerto)

Problema: Backend falla al iniciar
  Solución:
    docker-compose logs backend
    docker-compose down -v
    docker-compose up -d --build
